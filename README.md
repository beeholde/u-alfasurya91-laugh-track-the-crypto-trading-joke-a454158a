# Condolences, in One Word

A single-sentence submission for the make.fun contest **Laugh Track: The Crypto Trading Joke Contest**.

Running `main.py` creates `entry.txt` in `MAKEFUN_OUTPUT_DIR`, falling back to `/output` when that variable is unset.
